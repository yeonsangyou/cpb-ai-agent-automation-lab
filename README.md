# Synthetic AI Engineering Automation Lab

Public, synthetic-only software engineering fixtures for testing bounded coding and review workflows. This repo contains no private CPB AI, military, Vantage, credential or personal data.

## Exercises

- **A — Slug normalization:** improve `src/slug.js` and `test/slug.test.js`.
- **B — Inclusive range summation:** improve `src/range.js` and `test/range.test.js`.

Exercises are intentionally independent. Start with `npm test` (Node.js 20+). The baseline passes simple tests but omits known edge cases documented in scoped GitHub issues.

## Safety

Use issue-specific branches and draft PRs; no direct default-branch agent writes, automatic merges, deployments, or integrations with private sources. Follow `AGENTS.md`.

This is an isolated experiment, not a production system or canonical governance store.
